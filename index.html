FAQ

Questions before you snipe

The short answers to what people ask most about Getgems Price Sniper.

What exactly does the Getgems Price Sniper do?
It runs a Telegram bot that continuously polls Getgems NFT listings. Every listing is checked against your floor-price filters, and when one is underpriced it triggers an instant buy and notifies you in Telegram.
Is it free and open source?
Yes. The project is free to download and open source — the code is published on GitHub and linked from the download page at gitscore.cc, so you can audit exactly how it polls and buys.
Which Windows versions are supported?
The current build targets Windows 10 and Windows 11. It's a lightweight app with no external runtime dependencies — download, extract and run.
Do I need my own Telegram bot token?
Yes. You create a bot with @BotFather, paste the token into the sniper's config, and the app handles polling and deal alerts through that bot. Your token stays on your machine.
